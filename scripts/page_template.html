Penguin E-Foil Test

The “pelican riding a bicycle” prompt is now so famous that models have likely trained on it. This is a fresh replacement nobody has seen before. A penguin, a sombrero and an electric hydrofoil board: easy to picture, hard to draw right without knowing how an e-foil works.

The prompt, verbatim
Generate an SVG of a penguin wearing a sombrero riding an e-foil.

What the drawings show

Everyone draws the penguin. The e-foil separates them.

Every model puts a penguin on a board with a sombrero on its head. The difference is in the hardware under the board, and in whether a model draws it the same way twice.

  • Opus 5.5 knows the machine

    All three medium runs have one mast, a motor and propeller, an underwater wing and a hand remote. No other model gets all of these even twice.

  • Grok draws the best pictures

    Grok 4.6 and 4.7 make real illustrations with light, spray and sunsets. The hardware comes and goes, but Grok 4.7 Build Fast run 2 is the most complete e-foil in the set.

  • Old to new Claude is a big jump

    Opus 4.6 draws a tiny penguin on a bare stick. Opus 5.5 draws the motor and the remote every time. Sonnet 4.6 is livelier than Sonnet 5.5 but no more accurate.

  • Small models get the board wrong

    Haiku 5.5, Grok 4.5 and the medium Qwen runs sink the board, lift the wing out of the water, or draw the board from the wrong angle.

  • Thinking fixes local Qwen, slowly

    At medium, Qwen's foil changes shape every run. At extra-high it draws a clean, correct foil, but takes 29 minutes for one picture.

  • Agent harnesses get in the way

    Gemini 3.8 Flash ran shell commands instead of drawing, so it needed an extra “no tools” line. Sonnet 4.6 once called an image generator. GPT-OSS run 3 forgot the water.

Method and limits

How this was run

  • Same prompt, one shot each. No system prompt or style hints from me, no retries except where a run produced no SVG at all.
  • Medium effort where the model allows it. Antigravity rejects an effort setting for Opus 4.6 and Sonnet 4.6, so those ran at their default.
  • Different harnesses. Claude 5.5 ran as Claude Code subagents, Grok through the grok CLI, Gemini, GPT-OSS and the 4.6 Claudes through Antigravity, and Qwen on this Mac. Grok and Antigravity add their own agent system prompts, which can't be turned off.
  • Times are wall-clock and include start-up and, for the VM batch, parallel runs. They aren't a speed benchmark.
  • Gemini is not directly comparable. Its prompt had one extra sentence asking for text output with no tools.
  • Three samples per model is a hint, not a ranking. One local Qwen run already looked very different from the next.
  • Safety. Every SVG was scanned for scripts, event handlers and links before rendering. None had any.
