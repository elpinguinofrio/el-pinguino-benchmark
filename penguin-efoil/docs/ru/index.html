Как проводился тест
  • Один и тот же промпт, одна попытка, без нашего системного промпта.
  • Средний уровень рассуждений (medium), где он настраивается; иначе по умолчанию.
  • Показан каждый рисунок. Неудачные попытки сохранены в репозитории.
  • Разные среды запуска: Claude Code, grok CLI, Antigravity, MTPLX. Время включает запуск.
  • Gemini понадобилась одна лишняя строка: «не используй инструменты».
  • Каждый SVG проверен на скрипты и ссылки до рендера.
