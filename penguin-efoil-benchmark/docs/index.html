How it was run
  • Same prompt, one shot, no system prompt from us.
  • Medium reasoning effort where a model has the setting; otherwise its default.
  • Every drawing is shown. Failed attempts are kept in the repo.
  • Harnesses differ: Claude Code, grok CLI, Antigravity, MTPLX. Times include start-up.
  • Gemini needed one extra line: “do not use any tools”.
  • Every SVG is checked for scripts and links before rendering.
